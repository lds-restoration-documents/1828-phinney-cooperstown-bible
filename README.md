# 1828-phinney-cooperstown-bible
Markdown &amp; Plain Text extractions of the content of the 1828 edition of the King James Bible published by H. &amp; E. Phinney of Cooperstown, New York. In October 1829, Joseph Smith &amp; Oliver Cowdery obtained a copy of this version which was later used in the preparation of Joseph Smith’s new translation of the Holy Scriptures. Extracted using AI.
