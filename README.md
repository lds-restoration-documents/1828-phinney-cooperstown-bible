# 1828 Phinney Cooperstown Bible
[Markdown](#what-is-markdown) &amp; Plain Text extractions of the content of the 1828 edition of the King James Bible published by H. &amp; E. Phinney of Cooperstown, New York. 

## Background
In October 1829, Oliver Cowdery purchased a copy of the Phinney Cooperstown Bible which was later used by Joseph Smith in the preparation of his new translation of the Holy Scriptures.
* Joseph Smith Papers: [Joseph Smith's copy used for bible revision](https://www.josephsmithpapers.org/paper-summary/bible-used-for-bible-revision/5#historical-intro)
* BYU Studies: [Joseph Smith’s Cooperstown Bible: The Historical Context of the Bible Used in the Joseph Smith Translation](https://byustudies.byu.edu/article/joseph-smiths-cooperstown-bible-the-historical-context-of-the-bible-used-in-the-joseph-smith-translation)

## Files
* [phinney-bible.md](phinney-bible.md): the whole text in a single [Markdown](#what-is-markdown) file, without the marginal notes.
* [phinney-bible.txt](phinney-bible.txt): the same text as plain text, with no [Markdown](#what-is-markdown).
* [phinney-bible-sparse.txt](phinney-bible-sparse.txt): plain text of the biblical text only (books, chapters and verses), without tables, introductory material, contents or chapter summaries.
* [phinney-bible-pages/](phinney-bible-pages/): one [Markdown](#what-is-markdown) file per page of the scan (`page-001.md` to `page-884.md`), with running heads, verses, marginal notes and footers. File numbers are PDF page numbers.

## What is Markdown?
Markdown is a simple way of writing formatted text using plain characters, such as `#` for headings and `*asterisks*` for *italics*. A Markdown file is still readable as ordinary text, and can also be displayed with formatting. 
* Learn more at [markdown.org](https://markdown.org/).
* Tools for displaying, editing, or converting Markdown files: [https://markdown.org/tools/](https://markdown.org/tools/)

## Artificial Intelligence 
Extracted with Claude Code from Anthropic using Opus 5.5 and Sonnet 5.5 models.

Each page was transcribed from images of the scan, and the printed spelling, punctuation and printer's errors were kept as they appear. The verse text is reliable, but the tiny marginal cross-references are the weak spot: unclear readings are marked `<!-- uncertain -->` or `[illegible]` in the page files (roughly 2,300 and 240 of them). The first ~330 pages were checked against the scan a second time; the rest were not, and no page has been proofread by a person.

See [transcription-notes.md](transcription-notes.md) for how the text was extracted, the conventions used, and a log of uncertain and illegible readings.
